Política de Privacidade do bot videos

Última atualização: 1 de novembro de 2026

Esta Política de Privacidade explica quais dados o aplicativo bot videos acessa, como eles são usados, armazenados e protegidos, e como você pode revogar o acesso.

1. Quem usa o aplicativo

O bot videos é um aplicativo de uso pessoal, usado apenas pelo seu dono para publicar vídeos nos próprios canais do YouTube. Ele não é oferecido ao público.

2. Dados do Google que acessamos

Quando a conta Google faz login e autoriza o aplicativo, o bot videos pode acessar:

  • Informações básicas da conta (nome e endereço de e-mail), usadas apenas para identificar qual conta está conectada;
  • Informações do canal do YouTube (nome e identificador do canal), usadas para saber em qual canal publicar;
  • Permissão para enviar e gerenciar vídeos no canal autorizado, usada para fazer upload de vídeos e definir título, descrição, tags, miniatura e data de publicação.

O aplicativo não acessa e-mails, contatos, arquivos do Google Drive, histórico de navegação nem dados de outros usuários do YouTube.

3. Como usamos esses dados

Os dados são usados exclusivamente para publicar e gerenciar vídeos no canal do YouTube da própria conta que autorizou o acesso. Não usamos os dados para publicidade, criação de perfis, venda ou treinamento de modelos de inteligência artificial.

4. Armazenamento e segurança

O único dado guardado é o token de autorização fornecido pelo Google. Ele fica armazenado localmente, apenas no computador do dono do aplicativo, e é usado para que o envio de vídeos funcione sem precisar fazer login toda vez. O token não é enviado para nenhum servidor nosso nem para terceiros.

5. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados de usuários do Google com terceiros. Os dados só são enviados ao próprio Google (YouTube), como parte do processo de publicação dos vídeos.

6. Retenção e exclusão

O token fica guardado enquanto o aplicativo estiver em uso. Para apagar o acesso, basta revogar a permissão em myaccount.google.com/permissions. Depois disso, o token deixa de funcionar e é excluído do computador. Você também pode pedir a exclusão pelo e-mail de contato abaixo.

7. Políticas do Google e do YouTube

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

O bot videos usa os Serviços de API do YouTube. Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

8. Alterações nesta política

Esta política pode ser atualizada. A data da última atualização fica sempre no topo desta página.
